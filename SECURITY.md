# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/tirtauntario/show-cli/security/advisories/new).
Do not open a public issue.

Include the `show --version` output, your OS, and steps or a file that
reproduces the problem.

This is a spare-time project, so replies and fixes are best effort.
